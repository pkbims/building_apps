Words you can read out as they are, with the screen cue in front.

  • Written in your voice. Your recordings are already transcribed, and they open with "Hey folks, this is day one…" and use "so what happens is…". The script learns your phrasing from them, so it sounds like you and not like a blog post.
  • Short beats: 1–3 sentences each, one screen action per beat.
  • Transitions written in ("Now let me show you…"), so you never stop to think how to move on.
  • Length is set by the target: ~250 words is about 1:45 spoken. The draft shows its estimated time.

5Change 3: you say what the video is about

Two ways to make chunks, and both start with a prompt.

A · ⏱️ Recap with a focus

  • + → Recap still gives the time window (from the last recap until now), plus a new "What should this cover?" box.
  • Example: "only the decorMyRoom work, skip the content-system stuff".
  • How it filters: if the prompt names an app or folder, agents working elsewhere are dropped from the log summary before Claude sees it. Claude then keeps only what matches the prompt.
  • Empty box means everything, the same as today.
  • The draft's "What Claude saw" box shows which agents were kept, so you can tell if it missed one.

B · 📦 Past work

  • + → Past work, then a prompt: "make 4 chunks showing how I built the shopping prototype in decorMyRoom".
  • Step 1, an outline: Claude digs through the old conversation logs, git history and the files themselves. It then proposes an outline: N chunks, each with a title, what it covers, and what you'd show.
  • You review the outline in the same review window. You can drop a chunk, merge two, or ask for another.
  • Step 2, scripts: once you approve the outline, each chunk becomes a draft script, reviewed the same way.
  • The cost: digging takes 1–3 minutes, not 30 seconds, and uses more Claude usage. It only reads; it never changes files.
