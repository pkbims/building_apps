## Source notes

- **TAAFT** searches that worked: /s/couples+budget/, /s/split+expenses/, /s/stock+portfolio/, /s/crypto+portfolio/, /s/crypto+tax/, /s/trading+journal/, /s/crypto+trading/ (this one redirects to the task page). /s/couples+finances/ redirects to /task/couples-finances/ (2,136 subscribers, 1 tool). Each card shows two counts, e.g. "9,521 · 14". I recorded the larger one as *views* and the smaller as *saves*. Some cards also show another count next to the domain (probably clicks), which I left out. TAAFT has almost no couples-specific money tools: most "couples" hits are AI couple-photo generators.
- **Toolify**: search result pages don't show traffic, so I opened each tool page. Monthly visits and growth % come from Toolify's category rankings (/Best-AI-Tools-Category/Top-AI-ai-investing-Tools, -ai-crypto-Tools, -ai-for-finance-Tools). The traffic window ends Aug 2026, so growth is month-over-month for the latest month. Small tools (Crbit, Orla, SplitParty, TribeBills, Splitty, DollarDrip, Insightfolio) show "--" visits. Orla ("Banks, exchanges, wallets. One budget.", Freemium, added Aug 09 2026) is a new budget app covering banks plus crypto wallets; there was no traffic data, so it's not listed above.
- **YC**: search is keyword-based and noisy. "couples" returned Honeydue (S17, Acquired), Ivella (S21, couples banking, **status Inactive**, a warning sign for couples banking) and Coupl (S22, Active). Recent finance batches lean toward B2B and exchanges (QFEX, Sequence Markets, Arbital, Mochatrade = exchanges/brokers, skipped). No YC 2025–26 company built only for couples' money was found.
- **IdeaBrowser** (free plan): only cards are readable, so full reports were not opened. Searches: couples (29 ideas, mostly weddings and relationships), budget, finances, household, investors, stock, crypto (12), trading (11), split. All IdeaBrowser entries above are marked "idea, not shipped".
- Skipped as general platforms: Coinbase Advisor, Public, Pionex, KuCoin, Robinhood-style brokers, Expensify, Brex.
- No page failed 3 times. The Toolify JS extraction was blocked once ("Cookie/query string data") on utm links; I worked around it by reading the page text instead.
