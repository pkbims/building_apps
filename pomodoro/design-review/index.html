2The small-window problem has two halves

The layout is one half. The browser chrome is the other, and it's the bigger one.

Half 1 — the toolbar. A normal Chrome window can't get shorter than its tab strip + address bar, and can't get narrower than ~500 px. That floor has nothing to do with the widget. If you open the page as an app window (no tabs, no address bar), the floor drops to about 200 × 100 and the window looks like an actual widget — its own Dock icon, no URL bar, survives Cmd-W on the main browser.

open -na "Google Chrome" --args --app=http://localhost:7799 --window-size=360,560 --window-position=0,400

That one line is all it takes; no install. I'd also add a web manifest so Chrome offers "Install Pomodoro" in the address bar for a permanent Dock item. This is D5.

Half 2 — the layout. Even in an app window you'll drag it small, so the widget should re-flow: one layout for tall-and-narrow, one for wide-and-short, one for "barely there". D1 decides whether that's automatic or a single fixed layout.

Can't do: "always on top". No browser can pin a window above others. The nearest thing is macOS Stage Manager / a corner of a second desktop, or a tiny native wrapper later. Not in scope for a quick widget.

3Layouts — how the pieces sit

Every box is rendered at the pixel size written under it, with a genuinely long task name and four tasks, so what you see is what fits. Shown in the cube look; the look is a separate decision.

A · Stack (v1, fixed)

Task on top, clock, controls, list. Needs ≥ 430 px tall. The current widget, made fluid.

B · Split

Clock left, task + list right. Built for the wide-short shape a minimum Chrome window actually has.

C · Strip

A one-row mini-player: ring, digits, task, one button. Click the task name and the list drops down over it. Smallest possible footprint.

D · Clock with drawer

The whole window is the clock face, like the cube. Task name sits inside the face. The list is a sheet that slides up over it.

E · List-first

Timer shrinks to a header line; the list gets the space. For days when the list matters more than the clock.

D1 — Which layout?
"Auto" means the CSS picks by window shape — you never choose, you just resize. The others are one fixed layout.

4Looks — five, all on the Split layout so only the skin changes

A look is one block of CSS variables; the layout never touches it. Swapping later is free, so pick on taste.

  • Cube — white shell, black face, rainbow ring. The photo.
  • Mono — dark, one orange accent. Disappears into a dark desktop.
  • Paper — warm off-white, serif digits. Quiet.
  • LCD — green phosphor on black, mono digits, glow. Kitchen-timer nostalgia.
  • Glass — frosted panel over a pastel gradient. macOS-native feel.
D2 — Which look ships?
One ships by default; tick extras you want kept behind the theme button. Untick everything else and it gets deleted.
